API Testing

You can test the server's POST endpoint using curl or any HTTP client. Here are some examples:

Test GET Request

curl http://localhost:8080/
curl http://localhost:8080/about.html
curl http://localhost:8080/sample.txt -O

Test POST Request

curl -X POST http://localhost:8080/upload \
-H "Content-Type: application/json" \
-d '{"name": "test", "value": 123}'

Expected response:

{
"status": "success",
"message": "File created successfully",
"filepath": "/uploads/upload_20241010_123456_a7b9.json"
}

Test Keep-Alive Connection

curl -v -H "Connection: keep-alive" \
http://localhost:8080/

View Server Metrics

curl http://localhost:8080/__metrics__

Security Testing

The server includes robust security features. Try these to see security in action:

# Path traversal attempt (should return 403)
curl http://localhost:8080/../etc/passwd

# Invalid host header (should return 403)
curl -H "Host: evil.com" http://localhost:8080/

# Missing host header (should return 400)
curl -H "Host:" http://localhost:8080/
