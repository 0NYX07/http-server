✨ Server Features

Production-Ready Multi-threaded HTTP Server

Built from scratch with Go's low-level socket programming, this server implements the complete HTTP/1.1 protocol with advanced features for performance, security, and reliability.

🚀 Core Features

  • HTTP/1.1 & HTTP/1.0 Support: Full protocol compliance with proper version handling
  • GET & POST Methods: Complete implementation with proper status codes
  • Static File Serving: HTML, images, text files, and more
  • Binary File Transfer: Efficient streaming with Content-Disposition headers
  • JSON API: POST endpoint with validation and file storage

⚡ Performance Features

  • Worker Pool Pattern: Configurable thread pool (default: 10 workers)
  • Connection Queue: Automatic queuing when pool is saturated
  • Persistent Connections: HTTP keep-alive with configurable timeout (30s)
  • Request Limiting: Maximum 100 requests per persistent connection
  • Efficient Socket Reuse: Minimizes connection overhead
  • Non-blocking I/O: Goroutine-based concurrency

🔒 Security Features

  • Path Traversal Protection: Comprehensive validation against directory escape
  • Host Header Validation: Prevents host injection attacks
  • Input Sanitization: Validates all user input and paths
  • Rate Limiting: Per-IP request limiting (100/min)
  • Directory Listing Prevention: Only serves files, not directories
  • Content-Type Validation: Strict MIME type checking

📊 Monitoring & Logging

  • Structured Logging: Color-coded logs with timestamps
  • Thread Identification: Track requests by worker thread
  • Request Timing: Millisecond-precision performance metrics
  • Security Event Logging: All violations logged for audit
  • Metrics Endpoint: Real-time server statistics at /__metrics__
  • Connection Tracking: Monitor active and queued connections

🎯 Advanced Features

  • Graceful Shutdown: Clean connection termination on SIGINT/SIGTERM
  • Configuration Management: YAML config + CLI arguments
  • Panic Recovery: Automatic error recovery per connection
  • RFC 7231 Compliance: Proper HTTP date formatting
  • Multiple Content Types: HTML, JSON, binary streams
  • Custom Response Headers: Server identification, cache control

📁 Supported File Types

The server handles various file types with appropriate Content-Type headers:

  • .html, .htm: text/html (rendered in browser)
  • .txt: application/octet-stream (downloaded)
  • .png: application/octet-stream (downloaded)
  • .jpg, .jpeg: application/octet-stream (downloaded)
  • JSON API: application/json

🔧 Configuration Options

  • Server host and port (via CLI or config file)
  • Thread pool size (1-1000 workers)
  • Connection timeout (seconds)
  • Maximum requests per connection
  • Read buffer size
  • Listen queue size
  • Logging level (debug/info/warn/error)
  • Security feature toggles
